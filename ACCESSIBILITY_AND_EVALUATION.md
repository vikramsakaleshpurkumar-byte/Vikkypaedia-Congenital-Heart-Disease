# Accessibility and evaluation

The interface includes semantic controls, labelled inputs, visible keyboard focus, a skip link, reduced-motion support, text rationales, retry history, and an accessible mobile drawer with focus trapping and Escape handling. Source navigation focuses the requested PDF-page section. Desktop and 390px mobile checks exercise all seven modes. See the browser reports in build/ for the actual checks and outcomes.

Source figures have source-derived captions or fallback source-page descriptions. These are not comprehensive expert visual descriptions. Scanned/raster page views and visually structured tables remain less accessible than fully remediated semantic tables. Automated interface checks do not establish WCAG conformance. No screen-reader user study or formal accessibility audit has been completed.
