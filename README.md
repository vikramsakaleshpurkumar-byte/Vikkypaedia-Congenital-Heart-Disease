# Vikkypaedia · Congenital Heart Disease

Open [index.html](index.html) with the entire folder intact. It runs locally without an installer or server. This personal study course follows the supplied seventh edition and covers infancy through adulthood.

## Study modes

1. **Learn & read:** 29 chapter modules with measurable outcomes, five short learning units each, feedback, source links, reflection and a complete source reader.
2. **Heart atlas:** browse the clinical topics and selected source-linked concepts.
3. **Clinical features:** explore textual finding tags. Counts are lexical overlaps, not diagnostic probabilities; negation is not interpreted.
4. **Bedside reasoning:** search 145 authored recognition principles across anatomy, physiology and clinical findings.
5. **Flashcards:** 174 authored cards, six per chapter, with local self-ratings and an [Anki TSV](anki_course.tsv) export.
6. **Quiz studio:** 145 authored four-option questions, five per chapter, with explanations for every option and a random 25-question block.
7. **Visual spotter:** source image placements and vector diagram views with concealed/revealable captions and enlargement.

There are 15 fictional progressive cases and 45 staged decisions in selected modules. Findings and the final debrief appear as you advance. Guided practice reuses quiz items; the case decisions are additional practice.

Choose a chapter, read its outcomes, attempt a learning unit, and use the source button to inspect the cited original page. Continue through the units, try an available case, then record what you need to revisit. Essentials, Clinical Application and Deep Dive are authored cognitive levels; unavailable levels are disabled rather than padded. The 25-minute module estimate covers guided practice, not full chapter reading.

## Local records and portability

Progress, attempts, case responses, reflections and card self-ratings are stored in this browser. Use **Export my learning record** to save a JSON copy. Browser cleanup or another device can lose local progress; cross-device syncing is not implemented. Import the TSV into Anki using Front/Back/Tags and HTML fields. There are no remote analytics or login requirements in the local course.

Keep index.html, data/, figures/, tables/, references/, raw/, wiki/, and the supporting documents together. The ZIP is an offline package; uploading the ZIP itself does not create a working GitHub website. A private GitHub repository is a backup, and repository upload is separate from website hosting.

## Source and review

All 29 source chapters are included. The 512 body pages have complete original page views, and another 23 front/back/reference pages preserve the entire 535-page supplied source visually. Searchable text is a convenience extraction; use original page views for tables, equations, ECG labels and exact image credits. Standalone figure-caption pairing and vector crop bounds are automatic and have not been exhaustively visually checked.

The source PDF lists supplementary videos but contains no embedded video files. The [catalog](references/supplementary_videos.md) is retained as an inventory. The [printed index](references/printed_index.md) and [front/back matter](references/front_and_back_matter.md) are retained separately.

Teaching objects were authored by a model with checks of selected cited source passages. Technical verification does not establish clinical accuracy or competence. Independent congenital cardiology review and learner evaluation have not been performed. The course reflects the source edition; it has not been updated into a current treatment guideline.
